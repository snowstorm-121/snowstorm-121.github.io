# 访客统计静默状态条设计

## 目标

将最后一页的访客统计从显眼的大型玻璃卡，收束为社交入口之后的低优先级状态条。社交软件入口仍是联系页的唯一主视觉。

## 布局与视觉

- 统计保留在社交链接之后，使用单个、窄而低的圆角半透明玻璃容器。
- 桌面端容器宽度约 260–300px，高度紧凑；不再使用大标题、眉题或两个独立数字方块。
- 内容在一行中按“VISITOR LOG · 总访客 N · 今日 N”排列；统计不可用时保留现有破折号降级状态。
- “仅作匿名统计，不记录 IP”作为低对比辅助文字，紧贴状态条而不形成第二个视觉区块。
- 玻璃使用比社交按钮更低的对比度、阴影和悬浮幅度；不新增持续动画。

## 响应式与无障碍

- 窄屏允许状态内容自然换行，但不增加放大卡片、横向滚动或遮挡音乐 Dock 的行为。
- 保留现有 `aside`、标题关联、两个 `output`、`role="status"`、`aria-busy`、匿名 Cookie 和 Worker 接口。
- 保持减少动态模式下的静态呈现，以及既有失败安全降级。

## 非目标与约束

- 不修改 Cloudflare Worker、D1、计数口径、端点、Cookie、音乐、社交链接或页面其他区块。
- 不增加依赖、远程资源、第二个音频或新的统计数据。

## 验收

- 社交图标在视觉上明显强于访客统计条。
- 统计条桌面端不宽于 300px，内部不再有独立数字卡片。
- `320px` 窄屏无横向溢出，统计条与音乐 Dock 不相交。
- 原有统计接口、隐私文案、无障碍状态与主页测试保持完整。
