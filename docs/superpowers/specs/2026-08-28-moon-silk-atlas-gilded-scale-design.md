# 月白绢潮档案与鎏金羽鳞光标设计

## 目标

在现有“东方月海”档案入口基础上完成第二轮改版：让月海背景清晰可见，以优美流畅的潮丝表达真实文件关系，并以“鎏金羽鳞”替换当前近似箭头的月鳞光标。改版继续覆盖主页及三个档案入口，但不改写 PyTorch 笔记正文、阅读页系统光标策略或同步安全边界。

## 视觉方向

采用已批准的“C1 月白绢潮构图 + C3 鎏金羽鳞光标”。

- 将整页深色遮罩从当前约 76% 降至 42%–48%，目标是保留背景图约 55%–60% 的可见度。
- 不再通过整体压黑保证文字对比度；标题、导航、节点文字和题跋分别使用局部墨色渐隐、文字阴影或小范围背景晕染。
- 文字对比度最低保持 WCAG AA：普通文字 4.5:1，大字 3:1。
- 月海仍以冷蓝、月白为主；香槟金只用于当前选择、真实引用潮丝和光标脊线。
- 不恢复中央枢纽、放射硬线、玻璃卡、循环跑马、节点漂浮或地图视差。

## 学习档案的双层月海谱

学习入口保留“总览 + 七阶段”的主顺序，但每个阶段改为一处月湾，湾内显示该阶段全部文章的月鳞点。

- 总览作为近岸第一湾，其后依次为 Foundation、Stage 1–6，共八处月湾。
- 银白主潮贯穿八湾，表示稳定的阶段阅读顺序。
- 湾内月鳞点按 manifest 中的文章顺序排列；每个点是可聚焦的真实文章链接，并提供完整文章标题作为可访问名称。
- 聚焦或选择阶段时，题跋显示阶段标题、篇数、说明和阶段入口。
- 聚焦文章鳞点时，题跋切换为文章标题、所属阶段、直接引用关系和“阅读此篇”入口。
- 保留现有 `data-atlas-*` 选择契约与 `window.ArchiveAtlas.selectNode`；文章鳞点使用原生链接，不增加新的公开 JavaScript API。

生活页继续使用四处独立月湾，研究页继续使用由暗到明的四盏灯位。两页目前没有文章数据，因此不伪造文件依赖；只保留各自的分类关系或研究推进顺序。

## 真实关系数据

关联只来自可验证来源，不根据标题或内容进行 AI 推断。

同步器新增受 manifest 管理的 `learning/pytorch/atlas-relations.json`：

```json
{
  "version": 1,
  "stages": [{ "key": "stage-1", "label": "Tensor 与自动微分", "href": "./pytorch/stage-1/", "noteIds": [] }],
  "notes": [{ "id": "stage-1/day-1-...", "stageKey": "stage-1", "title": "...", "href": "/learning/pytorch/notes/...html", "order": 0 }],
  "sequence": [{ "from": "...", "to": "..." }],
  "references": [{ "from": "...", "to": "..." }]
}
```

- `id` 使用稳定的 `stageKey/slug`，不公开源文件绝对路径。
- `sequence` 来自 manifest 的阶段与文章顺序。
- `references` 只收录现有 Markdown 链接解析器成功解析到已发布笔记的链接；外链、图片、代码片段和无法解析的链接不进入关系图。
- JSON 加入 `generatedFiles`，参与同步检查、事务发布、恢复和旧文件清理；不得绕过现有 ownership、symlink、digest 或 journal 校验。
- 入口页加载 JSON 失败、版本不支持或字段无效时，保持现有八阶段静态潮痕与导航，不出现空白页或不可用入口。

## 连接线语言

连接线使用 SVG 三次贝塞尔曲线，但表现为潮丝而非技术图谱。

- 主顺序是一条连续银白潮痕，不绘制箭头、折线、直角或虚线。
- 跨文章引用使用 1px 以内的香槟金潮丝，端点落在月鳞点边缘而非文字上。
- 默认只清晰显示银白顺序；金色引用潮丝保持不可见或极低亮度。
- 键盘聚焦、鼠标悬停或选择某篇文章时，只显影该文章直接连入和连出的金色潮丝；无关关系保持隐藏，避免 32 个节点形成蛛网。
- 曲线控制点沿主潮切线展开：同向引用从潮痕外侧平滑抬升，逆向引用进入另一侧独立弧道。按跨度分配弧高，并交替上下通道，减少交叉和重叠。
- 关系显影只播放一次约 240ms 的局部月光扩散；不沿路径循环流动，不跟随指针重绘。
- 使用 `ResizeObserver` 在初次布局和断点变化后重算几何；普通 pointermove 不读取布局或修改路径。

## 鎏金羽鳞光标

新光标是 32×32 的非三角、非箭头形弯月羽鳞，由浏览器原生 CSS cursor 绘制。

- 热点固定在羽鳞前端，并与 SVG 的可见尖端精确重合。
- 常态为半透明月白鳞面、香槟金 S 形脊线和两缕细羽尾；可点击状态提高金色亮度，但不改变坐标、尺寸或热点。
- 装饰层只保留两段短小断续水光，跟随真实 `clientX/clientY` 缓动；不显示椭圆鱼群，不读取控件中心，不吸附或环绕。
- 点击反馈改为两段扩散月弧，圆心仍是实际 pointerdown 坐标；快速连续点击必须在最新落点重新开始。
- 文本输入、文本选择、触摸、粗指针、页面隐藏及 reduced-motion 继续恢复系统光标；生命周期继续保证单层、单 RAF、无重复监听器。
- PyTorch 时间线、阶段页和文章阅读页继续使用系统光标。

## 响应式与无障碍

- 1440px 与 1024px 显示完整横向八湾；允许题跋在 1024px 下移，但不压缩文件名称或制造横向滚动。
- 720px 以下切换为纵向潮卷，阶段月湾和文章鳞点保持原顺序。
- 移动端不绘制跨栏 SVG 关系网；当前文章下以内联“引用自 / 延伸至”链接表达同一关系。
- 所有阶段、文章和题跋入口均使用原生 button 或 link；焦点环不得被容器裁切。
- 未选文字保持可读，视觉弱化只作用于月湾、潮痕、鳞点和关联线。
- reduced-motion 下关系和选择状态立即切换，禁用所有连续动画与过渡。

## 验证与交付

- 严格执行 RED → GREEN；现有全量基线 220 项不得减少。
- 光标测试覆盖热点、无吸附、真实点击落点、快速连击、系统回退和生命周期。
- 同步测试覆盖关系 JSON 的确定性、内部链接解析、外链排除、manifest 管理、检查模式和事务恢复。
- 档案测试覆盖八湾与 32 篇映射、曲线只来自真实关系、数据失败回退、键盘/触摸选择、移动端关系文本和 reduced-motion。
- 浏览器验收 1440×900、1024×768、720×900、320×568；检查背景可见度、文字对比、潮丝交叉、焦点环、横向溢出和光标落点。
- 每个任务由独立实现 agent 完成并由独立 reviewer 审阅；最后执行全分支审阅。审阅批准后才合并 `master`、推送 GitHub并核对功能分支、本地 `master` 与 `origin/master` SHA。

## 边界

- 继续只在指定隔离 worktree 与 `feature/midnight-archive-atlas` 分支实施。
- 不修改 PyTorch 笔记正文、图片内容、旧公开 URL 或阅读页系统光标策略。
- 不新增 AI 推断关系、关系编辑器、搜索、筛选、缩放或拖拽图谱功能。
- 背景图片本身保持不变，只调整页面叠色、光线和局部可读性处理。
