本规格取代 2026-09-03《PyTorch 轨道档案与轨道准星设计》中关于档案视觉、关系图和自定义光标的决定。用户已选定「A · 海岸书页」、A1 夜色墨页、A2 月白纸页，以及「潮线刻度」主题开关；修订后的子页面同底色页眉已获认可。

- 主页保持现有布局、海岸背景、文案、搜索、短句、身份、三档案入口、联系、访客统计与音乐交互，不做左右分栏或其他视觉重排。只在现有导航栏加入「阅读模式」开关，并撤销自定义光标。主页始终保留当前夜海配色，即使用户选择白天阅读模式。
- `/learning/`、`/living/`、`/research/`、PyTorch 总览、七个阶段页与 32 篇笔记页采用统一的海岸书页视觉。所有子页面可切换夜间与白天模式。
- 删除且只删除四个旧博客 HTML 页面：`archives/index.html`、`archives/2023/index.html`、`archives/2023/12/index.html`、`2023/12/22/hello-world/index.html`。这四条旧 URL 失效是唯一获准的 URL 例外；不得修改其余公开 URL。
- 不编辑 PyTorch Markdown 源文、笔记正文内容或图片字节。同步器可以更新已发布笔记 HTML 的外层布局、导航、主题引入和样式，但 `.note-content` 的文章内容必须保持生成逻辑原样。
- 本轮只改指定隔离 worktree `/Users/yyy/Documents/Codex/2026-07-18/https-snowstorm-121-github-io-1-2/work/site/.worktrees/clock-lyrics-widget`。现有未提交 `.superpowers/sdd/task-4-report.md` 属于既有改动，必须保留。

## 视觉与页面结构

### 共享视觉语言

- 夜间底色 `#0a1623`、正文 `#eef2f4`、强调 `#d4b789`；白天纸色 `#f4f0e9`、正文 `#26333d`、强调 `#9a7047`。可为 WCAG 对比度微调次级文字和分割线，但不得回到厚重的异色顶栏。
- 子页面页眉与正文使用同一主题底色，只用细分割线区分；不叠加独立深蓝或亮白实色横条。照片仅用于上方横幅或局部图像区，标题所在区域有局部遮罩；文章目录、正文、代码块都位于稳定的不透明底色上。背景资源失败时保留可读的纯色与渐变回退。
- `/learning/` 和 PyTorch 页面继续使用现有 `coast-background.png`。生活与研究入口分别使用现有 `archive-living.jpg`、`archive-research.jpg`。不新增 AI 生成背景或复制参考站素材。
- 桌面目录采用左侧阶段/栏目索引、右侧内容列表；移动端按文档顺序竖排，不缩小桌面图形、不横向溢出。所有文字可选择，普通文本与交互文本至少满足 WCAG AA 4.5:1。

### 学习与其他档案

- `/learning/` 页首是清晰可见的海岸照片横幅，下面展示总览与七阶段的目录，以及所选阶段的真实文章标题、阅读顺序和链接。首次显示基础阶段；总览有独立入口与总览笔记。阶段切换由点击、Enter 或 Space 触发，不以悬停自动切换；阶段页的原有链接始终可见。
- 学习页文章数据只来自同步器生成且通过现有安全校验的 `/learning/pytorch/atlas-relations.json`；不从标题、正文相似度或 AI 推测关系。移除星盘、SVG 轨道、阶段射线、文章点、连线和焦点关系显示。JSON 仍作为公开数据与同步校验产物保留，不改变真实引用来源。
- 数据缺失、JSON 无效或脚本失败时，静态的总览和七阶段原生链接仍可使用，并清楚标示文章列表暂不可用；不得显示伪造文章或错误链接。
- `/living/` 与 `/research/` 分别保留现有四个栏目名称、说明和顺序。当前都没有已发布条目，因此只呈现明确的「尚未发布」状态，不设置虚假的文章目的地。

### PyTorch 总览、阶段与正文

- 总览页用同一目录语言展示学习计划与七阶段真实计数和链接；阶段页依 manifest 顺序直接列出文章，并保留前后阶段导航。
- 32 篇阅读页共用 A1/A2 版式：窄照片页眉、明确返回学习档案的导航、可访问的本页目录、舒适的正文栏宽、可读代码块与上一篇/下一篇。原有文章标题、正文、图片、目录锚点、内链和 URL 保持原意与目标；「返回星图」之类失效界面文案改为「返回学习档案」。
- PyTorch 页面外壳通过 `scripts/sync-pytorch.mjs` 的模板生成并进行同步校验，不手工逐篇改写生成文件。测试必须对照改版前后 `.note-content`，证明正文生成输出未改变。

## 阅读模式与系统光标

- 「潮线刻度」是一个固定在页眉的原生按钮，始终显示「昼」「夜」与当前刻度；主页旁标明「阅读模式」，以说明主页自身配色不随开关改变。按钮有可感知的当前状态、可见焦点环，支持键盘、触摸和屏幕阅读器。
- 首次访问且无手动选择时使用 `prefers-color-scheme`。手动切换后只存 `light` 或 `dark` 到同源 `localStorage`，跨页面与刷新保持；未手动选择时继续响应系统主题变化。存储不可用时当次切换仍生效，刷新后退回系统设置。其他标签页收到存储变化时更新。
- 子页面在首屏绘制前应用已保存的主题，避免明显的错误主题闪烁；同时更新适用页面的浏览器 `theme-color`。主页的 `theme-color` 与夜海配色保持原样。
- 主页及三档案页停止加载 `cursor-shoal.css`、`cursor-shoal.js` 与准星 SVG cursor。所有页面使用系统指针、链接手型、文本 I-beam；不增加跟随层、余迹、吸附或点击动画。

## 技术与验收

- 将共享的主题状态与潮线刻度行为放在独立、窄职责的资源中；子页面布局使用现有 `library.css`、`pytorch-reading.css` 以及档案专用 CSS 的主题变量，不大范围重构主页 JS 或同步器的正文处理逻辑。
- 先写失败测试，再最小实现并跑绿。不得删除测试来降低覆盖；当前基线为 248/248，最终全量测试数不得低于 248 且必须全部通过。更新不再适用的轨道/光标断言时，应以新布局、系统光标和回退合同的断言替代。
- 验证同步检查、相关 JS syntax 和 `git diff --check`；浏览器按 1440×900、1024×768、720×900、320×568 检查主页与所有页面类型的日夜模式、无横向溢出、页眉与底色协调、照片可见、背景失败回退。
- 验收键盘、触摸、文本选择、系统光标、reduced-motion、无脚本/关系数据失败回退；核查 32 篇文章及七阶段旧链接仍有效、四个旧博客页面不存在、站内没有指向它们的链接。
- 每项实施任务由独立 agent 完成 RED→GREEN→提交，再由独立 reviewer 审阅；问题修复后复审。全任务完成后进行独立全分支审阅；审阅批准且上述验证通过后，才在主 checkout 合并 master、推送并核对功能分支 HEAD、本地 master、origin/master SHA 一致。
