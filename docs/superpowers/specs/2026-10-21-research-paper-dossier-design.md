# ScholarLens / RetailFlow 纸本研究手札改版

## 决策与边界

用户在三案视觉稿中选择 C「纸本研究手札」，并确认只重做 `/research/scholarlens/` 与 `/research/retailflow/` 两篇案例页。`/research/` 总览、主页、学习与生活页、笔记正文、既有公开 URL 不改。保留两篇案例已有的事实、日期、指标口径、来源链接、昼夜切换与可展开技术细节；只为版式需要调整语义结构和少量导语。项目仓库仍只作只读证据来源。

## 视觉系统

两页共用案例专属的纸本版式，不改变全站公共头栏。移除案例页当前套用的深色海岸照片大横幅，改为无图的纸本封面：小号卷宗编号、项目名与中文名、短命题、细窄的双色资料条及明确的项目性质。日间采用偏暖纸白、深墨字与低饱和赭铜色；夜间采用深炭纸、温白字与适度提亮的铜色。不能把装饰做成未经证实的科学图形、任务完成徽章或假 UI。

不再让固定 260px 侧栏与正文长期竞争宽度。章节导航变成封面后的一行索引，在窄屏自然换行；正文维持舒适的阅读宽度。四段原有章节（问题航标、工程舱图、实验潮汐、结论星屿）以编号、留白、细规则线和页边注形成层级。大号数字只能配完整指标名称、分母/阶段和限制文字。避免重复的盒装卡片、阴影堆叠与纯装饰图标。

## 两篇案例的专属证据版式

ScholarLens 保留真实本地界面截图，改为「原始证据页」：清晰的图注说明它是公开论文演示、未计入正式评测，不能推出总体效果。检索成绩与生成成绩采用视觉上彼此独立的记录，明确 240 道可回答检索题与 100 题生成子集的不同分母；`0.6290` 是 EvidenceRecall@5，不是答案正确率，`0.3347` 是包含无答案题的整体 Answer F1。保留现有对照表、三例失败定位、来源和深度展开，不做误导性的转化漏斗。

RetailFlow 保留明确标注「流程示意」的模型提案—应用校验—用户确认—事务提交关系，图形仅根据仓库已验证流程制作。历史冻结 Test 的三组各 `0/4` 与当前已见 Dev 的 V5 `1/9`、V4 `2/9` 分为两条不同日期与阶段的记录，不直接比较。一次 Dev 取消的末态保留为「单例证据签」，不能提升为总体成功率。保留四题失败路径、保护层与真实模型演示的证据差别、来源和深度展开。

## 实现边界与交互

只修改两篇 HTML 及案例专属 CSS 规则；共享 CSS 中研究总览规则保持原状，新增/改动规则必须以 `.research-case` 为作用域。尽量复用现有 `reading-theme` 变量与切换脚本，不引入框架、外部字体、动态数据源或新的项目后端。章节锚点、GitHub 链接、表格语义、图片替代文字和原生 `<details>` 保留。背景/装饰资源失败时，纯色纸本仍能正常阅读。无动画依赖；键盘和触摸都能使用，`prefers-reduced-motion` 下无额外运动。
