# “烛微观澜”双层实验手札设计

## 目标与范围

在现有 `/research/scholarlens/` 与 `/research/retailflow/` 案例页增加有证据支撑的实验细节，让第一次访问的招聘/面试读者能迅速理解问题、工作、结果与限制，让想复核的技术读者能在同页展开数据口径、对照条件、失败轨迹和来源。`/research/` 总览只调整必要的案例入口文案，不在总览堆完整实验报告；主页外观、其他栏目、PyTorch 笔记正文及所有既有公开 URL 不变。两个源项目仓库仅作只读资料。

页面采用 B“实验手札”为主体：正文清晰、旁注承载数字和来源；章节间借用 A“航海日志”的克制航线感。C 式密集仪表板不采用。保留当前海岸书页与昼夜模式，不新增依赖、后端、构建步骤或跟随鼠标的装饰。四个小组件都保留，且每一个都必须解释一个真实实验问题，而不是作为纯装饰。

## 两层阅读结构

两页均保留“问题航标 → 工程舱图 → 实验潮汐 → 结论星屿”的章节顺序和当前 URL、锚点。默认可见层在每章用短段落说明问题、本人/上游边界、方法、关键结果与诚实结论，不要求展开就能读懂项目。技术层使用原生 `<details><summary>` 放在对应章节内；无需 JavaScript 即可读、可键盘操作，展开后仍保持可复制/选中文本，默认收起。

展开层只覆盖“能复核结论所需”的深度，不把两个仓库的整份报告搬到网页：实验样本与分母、冻结/开发版本、共同与变化条件、评分判据、代表性逐题失败、复现证据入口。每个数字邻近注明阶段/样本/版本；不能让分母不同的数值共用一个无说明的比例轴。来源优先链接到项目仓库中相应已公开报告；新增关键主张使用本轮核对的提交固定链接，避免未来 `main` 漂移造成证据错位。已有 README/上游来源入口保留。

## ScholarLens 页面与组件

默认层：限定单篇论文的证据问答；正文与问答标注隔离、段落/字符区间定位、BM25/Dense/RRF、Top-5 上下文、本地 Qwen3 4B 和引用审计；冻结 Test 中 Dense EvidenceRecall@5 为 0.6290（240 道可回答检索题），生成子集 Answer F1 为 0.3347（100 题），但 80 道可回答生成题有 22 道错误拒答。明确证据覆盖、答案质量、引用可追溯是不同判据。现有真实界面截图保留，注明演示题不入正式评测。

技术层包含：

- 检索设置与口径：2026-10-16 冻结 Test 共 300 题（240 可回答/60 无答案）；三路在相同 2400/200 切分、论文范围和 Top-5 口径下对照。BM25/Dense/Hybrid 的 EvidenceRecall@5 分别为 0.4654/0.6290/0.5901，AllEvidence@5 分别为 0.4250/0.5542/0.5250，MRR@10 分别为 0.3649/0.4965/0.4878。指标为 gold span 覆盖/排名，不是回答正确率；不能泛化为 Dense 普遍最优。
- 生成设置与口径：预先冻结 100 题（80 可回答/20 无答案），只跑 Dev 所选 Dense；Top-5 最多 4500 context tokens，本地 `qwen3:4b-instruct-2507-q4_K_M`、temperature 0、seed 42。Answer/Evidence F1 为 0.3347/0.3790，错误拒答 22/80、无答案题正确拒答 17/20、错误回答 3/20、输出截断 9/100。整体 F1 含无答案题，不能等同可回答题质量；100 题生成子集与 240 题检索全量不得画成因果漏斗。
- 三条代表性轨迹：`1911.06815` 检索 Top-10 未覆盖 gold；`1805.04579` 完整替代 gold 排第 6、被 Top-5 排除而非 token 截断；`1804.07445` Top-1 完整覆盖 gold 仍拒答。只用于定位“检索 → 上下文交接 → 生成”阶段，不能当故障频率估计，也不公开本地忽略目录中的逐题文件。

“证据刻度”把上述检索与生成样本分成独立的两个标尺，直接标注分母、指标含义和坏/好方向；“失败轨迹”按三阶段显示具体可核实的输入、观察和定位，技术层给出论文 ID 与来源报告。小组件可用 HTML/CSS 实现，信息在无装饰样式时仍按语义顺序阅读。

## 视觉与交互约束

- 旁注使用现有纸色、墨色、月海色和香槟金强调，不额外引入新视觉主题；航线只作小范围章节引导，不画跨页面蛛网、箭头或大面积装饰。无动画也能理解，不覆盖文字/照片。
- 四组件以标题、数值、分母、来源/解释构成；颜色只作辅助，失败/成功不能只靠颜色辨别。不同样本的比例条若出现，必须分别标注并保持数学比例准确；RetailFlow 历史 Test 与当前 Dev 不共用暗示进步的横轴。
- 1440×900、1024×768、720×900、320×568 四视口与昼夜模式均无水平溢出。窄屏旁注下移，展开层自然纵排；长 ID、链接和表格可换行或局部滚动，不裁切结论。
- `<summary>` 的点击/触摸目标至少 44px，键盘焦点可见，原生 Enter/Space 可操作；表格保留 caption/表头，真实截图保留 alt，装饰标为隐藏。尊重 reduced-motion；文本可选择；系统光标不变。背景图加载失败时现有底色仍须让内容可读。
