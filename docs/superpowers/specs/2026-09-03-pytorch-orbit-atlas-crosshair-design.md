# PyTorch 轨道档案与轨道准星设计

## 决策

本规格取代此前“月白绢潮／鎏金羽鳞”在学习页航线图与自定义光标上的视觉决策。参考 [Yuliang Liu · Document Image Intelligence](https://www.yuliang-liu.com/) 的中心锚点、同心轨道、阶段射线与重点节点的层级语言，但不复制其素材、文字或褐黑配色。

学习页的中心锚点是可验证的 `PyTorch 总览`。七个阶段从中心按固定角度向外放射；每一个阶段在自身分支上承载该阶段的真实文章阅读顺序。中心到阶段的暖色射线表达实际的“总览 → 阶段”目录层级；同阶段文章间以雾白细线表达 manifest 顺序。当前 `references` 为零，不绘制或暗示跨文引用；未来只有同步器生成的真实 JSON 引用可在文章聚焦时以低饱和香槟金线出现。

## 视觉

- 保留主页的 `coast-background.png`、深海蓝底、月光与下缘山影；不得引入参考站的褐黑背景或复制其图形。
- 轨道是低对比冰蓝等高线，文章点是雾白，中心与阶段准星是低饱和香槟金。香槟金只用于中心、阶段和当前焦点。
- 桌面星盘具有中心、三层轨道、七条目录射线、七条阶段支线和 32 个文章点；所有线段必须由现有 `atlas-relations.json` 派生，禁止装饰性网格或猜测关系。
- 阶段标签紧邻其准星；文章标题不直接压在星盘上。焦点或选择时，题跋提供阶段或文章的完整名称、说明、实际链接与可验证直接引用说明。
- 不使用月湾椭圆、水波、贝塞尔潮丝、玻璃卡、漂浮节点、连续粒子动画或指针驱动重绘。

## 轨道准星光标

- 用两个同几何的 28×28 SVG 原生 CSS cursor 表达普通与可点击状态，热点固定在视觉中心 `(14,14)`。
- 图形由雾白外环、冰蓝短刻度和低饱和香槟金中心组成；可点击状态只能提升中心与刻度颜色，不改变尺寸、热点或形状。
- 删除 `cursor-shoal.js` 产生的 DOM 跟随层、两段余迹、点击水波、RAF、缓动与事件监听。页面不再自行绘制跟随光标或点击效果。
- 输入框、文本选择、触摸、粗指针、reduced-motion、页面隐藏以及 PyTorch 时间线、阶段与正文阅读页恢复系统光标。主页和三个档案入口才启用准星光标。

## 布局、回退与无障碍

- 在 1024px 及以上完整显示响应式 SVG 星盘；不得让中心、阶段标签、文章点或焦点环重叠、裁切或造成横向滚动。
- 在 720px 以下关闭桌面 SVG 星盘：先显示总览，再按 `00` 到 `06` 的 manifest 顺序纵向渲染七个阶段及文章链接；不绘制缩小、不可读的星盘。
- 关系 JSON 失效、版本不支持或加载失败时，仅显示总览与七阶段静态原生入口，且不挂载动态文章点或关系 SVG。
- 背景资源失败时使用深海蓝 CSS 回退、低对比山影色块和可读文字／轨道；普通文字保持 WCAG AA 4.5:1。
- 所有导航仍是原生 button/link，完整可见的 `:focus-visible` 焦点环不能被容器裁切。reduced-motion 立即切换状态，不使用连续或指针驱动动画。

## 约束与验收

- 不修改 PyTorch Markdown 正文、已发布 HTML 笔记、图片内容、旧公开 URL、同步器关系来源或 `atlas-relations.json` 的真实数据。
- 保留 `window.ArchiveAtlas.selectNode` 与当前 JSON 校验／安全回退契约；不得用新公开 JavaScript API 替换原生文章链接。
- 新增或调整测试覆盖：中心/七阶段/32 文章映射、目录射线只由阶段数据产生、零引用无额外连线、无效数据回退、桌面与移动断点、键盘、触摸、文本选择、系统光标回退、背景失败与 reduced-motion。
- 浏览器验收 1440×900、1024×768、720×900、320×568；全量测试不得低于当前 238 项，并运行相关 JavaScript syntax、同步检查和 `git diff --check`。
