# 海岸研究作品集

## 授权与问题

用户认为研究总览与三个项目展示仍不精美，明确授权助手自行决定设计、编写方案、审核、实施并发布，全程无需询问。范围为 /research/ 和 ScholarLens、RetailFlow、ToolTune 三篇案例。主页、学习、生活、笔记正文、公开 URL 不变。只在指定 clock-lyrics-widget worktree 修改；保留现有 dirty task-4-report.md。基线 1b2ed5d，342 项测试。

现状缺点：总览是同质的纯文字列表；案例首屏只有标题和无意义的条纹；视觉证据出场过晚；数据、工程与长文在相似灰线中缺乏阅读节奏。本轮解决图文结构与项目辨识度，而不是再添加一组装饰小组件。

## 方向决策

考量三种方案：纸本细节修饰（改动小但结构问题仍在）、深色实验控制台（数据醒目但与主页和日间模式不协调）、海岸研究作品集（图文展区+各项目真实证据，可兼顾美感与深读）。采用第三种。延续海岸的蓝绿、纸白与暖砂色，不复刻海岸照片大横幅。保持全站原生昼夜开关。

日间背景暖白 #f5f3ee，正文深墨 #203136，弱文字需达到可读对比；夜间背景 #101b22，正文 #edf2ef。项目分别以沉静海绿、陶土铜、雾蓝点缀，颜色只作身份区分，不承担成功/失败的唯一表达。使用系统中文字体、Georgia 拉丁标题，不引入远程字体。避免巨圆、发光轨道、玻璃叠层、假代码终端或虚构图表。

## 总览：三幅项目展区

宽屏内容最大 1200px，顶栏沿用现有链接和开关。首屏为 约 65/35 的文字/海岸图像布局：烛微观澜标题、短引言“从原文证据，到执行边界，再到模型训练。”和简明索引；右侧使用现有 archive-research.jpg 的裁切作为氛围，纯色回退。图片不是项目截图或实验数据。

原 260px 目录侧栏改成紧凑的横向三项项目索引，与展示区共享宽度。项目使用三个宽幅展区，不挤成三列小卡：图版约 55%、说明约 45%，第二项在桌面交错排列，移动端均图版在前、文字在后。保留全部现有项目简介、状态、GitHub 与案例入口；可以增加一句项目命题。每项包含编号、项目名、克制的技术标签、视觉证据、完整限定的关键结果、主入口。只有“阅读案例”作为主要动作，GitHub 为次级文本链接。点击区域不嵌套，不将整个卡片伪装为按钮。

1. ScholarLens：真实 research/assets/scholarlens-demo.png 放在有留白的海绿底证据图版，不能切掉重要截图内容或用假 UI 替代。紧邻图注“真实演示界面 · 不计入正式评测”。说明核心是单篇论文内可回看的证据；关键发现 0.6290，完整标注“Dense EvidenceRecall@5 · 冻结 Test 240 道可回答题”，并说明这是证据覆盖而非答案正确率。来源沿用现有正式报告。
2. RetailFlow：HTML 有序流程图版，四步“模型提出 / 应用校验 / 用户确认 / 事务与回执”，标“流程示意”，加参数变化使旧确认失效的说明。设计感来自结构、精确间距、角色编号与细线，不使用全绿完成状态。历史 Test 展示 B0/B1/B2 各 0/4（2026-10-20），说明业务效果未达标；不把保护层正确性冒充模型成功。
3. ToolTune：HTML/CSS 真实比例对照图版，两条共享 0–100% 量尺的水平条：B0 89/190（46.84%），U200 100/190（52.63%）；数值文本始终可见，条仅辅助。标题“严格决策匹配 · 冻结均衡 Test”；下方记录“17 题改善 / 6 题退化”。注释“95 调用 + 95 非调用；不代表真实 API 成功或生产流量准确率”。不使用伪造训练损失曲线或跨项目排行。

三种图版复用同一视觉语法但不套同一信息图。总览里的数值相互不可比较，禁止形成统一排行。

## 案例：有证据的首屏与完整研究记录

三篇案例均采用两栏首屏，左侧编号、原有 h1、项目性质、原导语、标签、“查看实验结果”锚点；右侧使用同项目图版（ScholarLens 截图、RetailFlow 四步示意、ToolTune 比例条）。保留原 h1 文案及 aria label；图注与限制就近出现。图版为事实的摘要，不新增事实，不移除正文的来源。

首屏下方是三栏简短的项目资料带（语义 dl）：研究范围、工程方法、证据边界；不用没有分母的大数。ScholarLens 区分检索 240 题和生成 100 题；RetailFlow 区分历史冻结 Test 与当前已见 Dev；ToolTune 区分 Validation 选模与 Test 190 题。这些内容只摘自已有正文。

删除首屏条纹装饰。正文保留四章 ID、编号、完整论述、表格、原生 details、真实截图、证据链接和负面结论。现有 article.archive-content 内 HTML 字节不变（新增视觉在 article 外部；正文通过 CSS 改善）。阅读区最大 820px，正文行高约 1.85，段落之间有呼吸；章节使用小编号、细线和明确的标题层次。宽屏章节索引作为 150px 窄侧栏可 sticky，1024px 以下恢复静态横向换行。侧栏不能比视口高而产生不可达链接。

现有 evidence ruler、phase ledger、paired record、流程、details 统一使用更柔和的底色和留白；保留不同样本/阶段的标签。表格的 numeric td 不拆行，窄屏只在可聚焦表格 region 内横向滚动。所有新增图示数值均保留完整文本，不仅靠颜色或条长。ScholarLens 首屏摘要截图和正文原始大图有明确预览/证据层次。
