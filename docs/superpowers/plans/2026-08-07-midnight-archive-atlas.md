# 午夜航海星图档案与“月鳞鱼群”光标实施计划

## 概要

保留主页现有四幕结构，将三张档案卡分别连接到完整独立页面。新页面借鉴参考主页的星座选择与路径联动，但采用“航海星图”构图，融入现有深海蓝、月光青、金色反射与液态玻璃语言。学习档案同步知识库现有 32 篇 PyTorch 笔记；生活与研究档案先建立可扩展框架。现有游鱼光标同时升级为更精致的“月鳞鱼群”。

## Task 1：升级“月鳞鱼群”并修复档案卡吸附

- 先增加失败测试，复现游鱼进入 `.archive-card[data-preview]` 后固定在卡片中心的问题。
- 档案卡图片、标题、正文和空白区域允许自由跟随；只有按钮、链接等真实控件触发聚拢。
- 主鱼改为约 `14×8px` 的水滴鱼形轮廓，使用月白鱼腹、青色尾鳍和柔和边缘光，不增加图片资源。
- 主鱼朝向根据运动向量计算；低速平滑转向，高速快速响应，避免突然翻面。
- 六条小鱼使用不同阻尼、距离和横向偏移组成浅 V 字编队，转弯时依次跟随。
- 停止移动后，小鱼在主鱼附近轻微摆尾和呼吸，不形成固定圆环。
- 快速移动产生最多约 `180ms` 的三段鳞光残影；停止后完全消失。
- 靠近真实控件时，鱼群围绕控件做小范围环游，不静止堆叠在中心。
- 点击时六条小鱼沿弧线散开约 `32–46px`，随后回游归队；金色反光只在点击瞬间出现。
- 夜航模式使用冷白月光强调，普通模式保持青蓝色。
- 保持一层 DOM、六条小鱼、单一 RAF，不增加临时粒子、计时器阵列或第二套动画循环。
- 减少动态、触摸设备和粗指针环境停用自定义光标并恢复系统光标。
- 将实现抽成共享模块，供主页与三个档案入口页复用。

## Task 2：建立 PyTorch 一键同步流程

- 固定普通同步命令：`npm run sync:pytorch -- --source "/Users/yyy/Documents/知识库/Notes/Pytorch学习"`。
- 首次资源抓取命令追加 `--fetch-remote-assets`；检查模式追加 `--check`。
- `markdown-it` 仅作为本地构建依赖；线上仍是纯静态 HTML。
- 同步全部 Markdown，生成 7 个阶段、32 篇文章；保持现有 24 篇文章 URL 不变，新文章使用确定性 slug。
- 支持表格、列表、任务清单、引用、代码块、Markdown 链接、Obsidian 双链和图片嵌入。
- 将被引用的 `Day5.py` 复制为本地附件，文章中显示可折叠源码和下载入口。
- 首次下载现有 29 张远程图片并转成本地资源；普通同步遇到新的远程图片时中止并提示。
- 缺失图片视为错误；失效双链保留为普通文字并产生警告，不生成死链接。
- 同步前检查常见密钥和私钥形态，命中时报告文件与行号并停止。
- 只清理由生成 manifest 管理的旧文件，不删除其他资源；`--check` 验证输出与知识库一致。

## Task 3：建立三个“午夜航海星图”入口页

- 保留 `/learning/`（星野问津）、`/living/`（人间照影）、`/research/`（烛微观澜）。
- 顶部提供返回主页、当前档案标题和三类档案切换。
- 左侧为无厚重外框的海岸星图，右侧为窄幅折射玻璃索引。
- 节点选择同步改变航线、光晕、计数和说明；其他星区降低亮度。
- 鼠标、键盘 Enter/Space、焦点和触摸共享同一状态逻辑。
- 手机改为星图在上、横向档案切换、详情在下；减少动态关闭漂移、视差、路径绘制与弹性转场。
- 学习页以 PyTorch 为中心，周围排列七个学习阶段，默认展示“32 篇／7 阶段”。
- 生活页保留“长夜微澜、纸上星河、山河来信、岁序留痕”。
- 研究页使用“问题航标、实验潮汐、工程舱图、结论星屿”。
- 空目录可被选择并展示“尚待启航”，但不创建空白页面或失效链接。

## Task 4：PyTorch 时间线与阅读页

- `/learning/pytorch/` 使用“潮汐时间线”表现七阶段学习进程。
- 阶段页按学习顺序列出文章，并显示篇数及上一篇/下一篇。
- 阅读页采用窄正文、桌面可折叠目录、阅读进度与返回星图入口。
- 手机端目录折叠到正文顶部，不占用固定侧栏。
- 表格、代码、引用、任务清单、实验图片和附件使用统一深蓝玻璃样式。
- 阅读页使用系统光标并减少连续动画，保证长文阅读不受干扰。
- 不改写笔记原文，本机路径继续作为代码文本展示。

## 全局约束

- 保留主页搜索、动态文字、音乐播放器、唯一 `profileAudio`、夜航、访客统计及社交入口。
- 不增加浏览器运行时依赖、第二个音频、远程字体或线上远程图片。
- 复用现有海岸背景，不把概念草图作为网站资源。
- 当前基线为 68/68 通过；每项任务执行 RED、GREEN、独立提交与独立 reviewer。
- 浏览器验收 1440×900、1024×768、720×900、320×568，并覆盖减少动态与粗指针。
- 仅在指定 `clock-lyrics-widget` 隔离工作区和 `feature/midnight-archive-atlas` 分支实施，不修改、删除或重置主 checkout。
