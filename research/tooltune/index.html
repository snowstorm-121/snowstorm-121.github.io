01 / CHAPTER

问题航标

模型说“我会调用工具”与真正生成可解析的工具名、参数，是两种不同结果。ToolTune 把问题缩到单轮决策：该调用还是不调用；若调用，能否完整输出指定工具及参考参数。这里没有运行真实 API，文本调用正确不等于外部动作成功。

实验在 Apple M5、16 GB 统一内存上，用 MLX 4-bit Qwen3-4B-Instruct-2507 的冻结基座训练 rank 8 LoRA。它是本地量化微调与冻结对照实验，样本来自 Glaive；主要看一组可审计的诊断结果，而非生产流量准确率。

02 / CHAPTER

工程舱图

112,960 条原始对话中，99,108 条通过严格解析。畸形角色、未知工具与参数 schema 错误进入隔离记录。训练与评测按完整来源对话、工具家族及既定近重复规则连通分组，避免把同一组拆到不同 split。随后在模型正式评测前固定均衡抽样：Validation 100+100，Test 95+95，分别是调用与非调用。规则内交集审计为零，不代表语义或预训练层面绝无泄漏。

可训练范围
最后 4 个 block 的 q/v · rank 8 · 327,680 个可训练参数；MLX scale=16 是直接乘数，不是 PEFT alpha。
正式预算
200 次 optimizer updates / 800 个 microsteps；4,000 条训练池中实际曝光 800 条、40,821 个监督 token，未遍历完整一轮。
Validation 选模
B0 94/200、U100 103/200、U200 107/200；选择 U200，未用 Test 调参。

训练修正使用 MLX-LM 支持的 loss 回调，不修改安装包源码。模型架构、量化和优化器由上游实现；项目工作集中在数据处理、训练编排、目标遮罩与可复核评测。

实验潮汐

冻结 Test 是预先确定的均衡诊断集，95 个 gold 调用、95 个 gold 非调用。B0 无 adapter 与 Validation 选中的 U200 从同一冻结基座独立加载；逐题 prompt token 相同，均为 greedy 解码、EOS 停止、256-token 上限、无强制 JSON。金标准不进入输入；首次预测中的截断、解析失败与空输出照常计错且保留分母。

展开实验手札 · 配对变化、标签疑点与评分边界

从首次输出复算

实验契约在生成前锁定基座、adapter、模板、数据、样本 ID、解析器与指标。两臂各保留 190 条首次预测，逐题输入 token 完全相同；离线复算与总分一致。严格决策匹配要求调用的工具及参考参数一致，或非调用在预算内完整结束。调用召回、工具名和 schema 的分母均为全部 95 条 gold 调用，不以生成的调用数重新设分母。

配对为 83 都对、17 改善、6 退化、84 都错。改善中的 7 题来自非调用完整结束、6 题来自调用包裹恢复、4 题来自参考参数对齐。截断 B0 72/190、U200 66/190，改善并未消除输出预算问题。

真实样例如何读

play_music 成功样例没有触发实际播放器。日历样例 glaive-v2:037855:a4 的口头承诺不是工具调用。Ruby 样例 glaive-v2:081350:a2 的拒绝回答按动作计对，但不证明回答质量。另有 glaive-v2:095636:a4 的参考参数含可见上下文未给出的密码；仍按冻结参考计分，不将匹配它解释为安全的密码提取。这里不展示密码原文。

样本覆盖与外推

所有 held-out 调用题都只有一个候选工具；Test 95 个非调用题中仅 1 个带可用工具。这里不能证明复杂多工具路由、广泛“工具可用但不适配”的拒绝、自然语言质量或真实 API 成功。局部只读工具演示使用构造调用文本，不计入 Test。

04 / CHAPTER

结论星屿

这一轮固定预算实验在均衡诊断 Test 上观察到严格决策匹配 89/190→100/190，同时留下 6 题退化与 66/190 题截断。它说明部分输出格式和预算内完成状态改善；当前数据不足以声称广泛工具选择能力、自然语言质量或真实 API 执行成功率提高。

原创工作包括解析与隔离、分组抽样、训练编排和 loss mask、冻结契约、评分与复算。MLX/MLX-LM、Qwen、Glaive 的模型、量化、优化器与数据归上游；使用的量化权重是社区转换。68 项工程测试核对实现路径，不等于模型质量。原始数据、模型权重、adapter 和完整原始预测未随公开仓库发布，不能声称一键完整复现。
