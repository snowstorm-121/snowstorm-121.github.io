  2. 02 / BOUNDARY

    零售 · 执行

    RetailFlow

    实验原型

    模拟零售环境中的本地 CLI Agent，探索工具执行前的身份校验、用户确认与事务恢复边界。

    主要工作：具体参数提案、确认失效机制、SQLite 事务回执与冻结评测；不连接真实订单或支付。

    • CLI Agent
    • 参数确认
    • 事务恢复
