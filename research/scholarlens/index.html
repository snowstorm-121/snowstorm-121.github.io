问题航标

阅读论文时，生成式回答可能省略实验条件，或给出无法核对的引用。ScholarLens 将问题限定在用户选定的单篇论文，展示对应原文，让读者核对方法、数据集与实验设置。

这是本地 RAG 研究原型；当前结果来自英文 QASPER 题集与单机 4B 模型。

工程舱图

QASPER 正文与标注分开导出，问题、答案和证据标注不进入检索索引。段落位置与规范化字符区间用于定位原文，gold evidence 绑定原文位置，而非某次切分的 chunk ID。

查询先限定论文，再进行 BM25、Dense 或 RRF 混合排名。Dev 选择的最终配置为 2400/200 字符切分与 Dense；Top-5 原文组成上下文，由本地 Ollama 的 Qwen3 4B 生成回答或证据不足拒答。

引用检查核对引文是否来自本次上下文，并保留问题、检索排名、context、prompt、模型响应和审计记录，便于追踪失败阶段。

同条件检索对照

2026-10-16 冻结 Test 共 300 题，其中 240 道可回答、60 道无答案；三路共用 2400/200 字符切分、论文范围与 Top-5 证据口径。AllEvidence@5 衡量整组标注证据完整覆盖，MRR@10 衡量首个命中位置，均不是答案正确率。

BM25 / Dense / RRF Hybrid 的 AllEvidence@5 分别为 0.4250 / 0.5542 / 0.5250；MRR@10 分别为 0.3649 / 0.4965 / 0.4878。这次 Dense 在 @5 占优，不代表对所有论文普遍最优。

独立的生成子集

预先冻结的 100 题生成子集为 80 道可回答与 20 道无答案；Dense Top-5 最多 4500 context tokens，本地 qwen3:4b-instruct-2507-q4_K_M，temperature 0、seed 42。整体 Answer F1 0.3347、Evidence F1 0.3790；无答案题正确拒答 17/20、错误回答 3/20，输出截断 9/100。整体 F1 含无答案题；不能和 240 题检索结果作因果比较。

失败轨迹：先定位阶段

  1. 检索未召回 · 1911.06815

    实验数据集问题的 Dense Top-10 未覆盖任何 gold；拒答没有凭空编造，但证据未进入候选。

  2. 候选交接 · 1805.04579

    模型权重问题的完整替代 gold 排第 6，被 Top-5 排除；不是 4500-token 截断。

  3. 生成拒答 · 1804.07445

    数据语言问题的 Top-1 已完整覆盖 gold，模型仍拒答；此例不能归咎检索。

三例用于定位阶段，不代表故障类型占比。原始报告：冻结 Test、失败轨迹。

结论星屿

可定位引用便于核对，不保证事实正确。当前未做跨论文综合，也不是生产服务；小规模英文题集、单机模型与缺少独立人工 gold 全量审核限制了结论范围。

项目复用 Kotaemon 的 Gradio 应用、存储和模型接入组件，以及 QASPER 数据与官方评测资源。本项目改造集中于论文数据定位、正文与标注隔离、论文范围检索、引用审计和冻结评测。部分工程与报告由助手协作完成，不代表全部模块由作者独立手写。
