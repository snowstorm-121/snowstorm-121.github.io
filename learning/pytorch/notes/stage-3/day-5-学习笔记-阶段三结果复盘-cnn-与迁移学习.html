一、复盘边界：这次复盘的是哪一个实验

本次不重新训练模型，也不把 Day 5 变成新的模型比较实验，而是复盘已经跑通的这一条迁移学习闭环：

CIFAR-10
-> ImageNet 预训练 ResNet18
-> 冻结 backbone
-> 将 Linear(512, 1000) 替换为 Linear(512, 10)
-> 只训练新的分类头
-> 根据 validation 选择 best_state
-> 加载最佳权重后进行最终 test

这属于固定特征提取器策略，不是 fine-tune。backbone 仍然参与 forward，将图片转换成特征；只是其参数不通过反向传播更新。分类头负责把 [B, 512] 特征映射为 [B, 10] 的 CIFAR-10 logits。

三、如何分析训练与验证表现

3.1 从曲线和指标观察事实

2 个 epoch 内：

  • train loss 从 0.5802 降到 0.3857；
  • val loss 从 0.4149 降到 0.3695；
  • train accuracy 从 81.85% 升到 86.97%；
  • val accuracy 从 85.26% 升到 87.14%。

训练和验证 loss 都下降，训练和验证 accuracy 都上升，说明模型在这段训练过程中仍然在学习。因为验证集表现没有恶化，所以当前没有明显的过拟合证据。

3.2 为什么 validation accuracy 略高于 train accuracy

两轮中 validation accuracy 都略高于 train accuracy，这不一定表示代码错误，常见原因有：

  1. 训练集使用了数据增强，样本更难；验证集使用未增强的图像，分布更稳定。
  2. 训练阶段处于 model.train()，验证阶段处于 model.eval()。
  3. BatchNorm、Dropout 等层在训练和验证模式下行为不同。

因此，不能单独根据“验证准确率高于训练准确率”就断定模型异常或数据泄漏。需要结合数据预处理和模块模式一起判断。

3.3 validation 与 test 的关系

最佳 validation accuracy 是 87.14%，最终 test accuracy 是 86.67%，相差 0.47 个百分点。两者接近，说明当前测试结果与验证阶段的泛化估计基本一致。

这里必须保持职责边界：

train      -> 更新参数
validation -> 选择 best_state
test       -> 最终一次性评估

不能因为测试结果不理想而反复查看 test 并据此调参，否则测试集就不再是独立的最终评估集。

四、为什么 CNN 比纯 MLP 更适合图像

4.1 CNN 保留局部空间结构

图像中相邻像素通常具有更强的关系，边缘和纹理往往由局部区域构成。Conv2d 使用局部窗口处理输入，因此能够直接利用这些邻域关系。

纯 MLP 往往先把图像展平为向量。展平后的数值仍然存在，但“哪些像素相邻”不再由模型结构显式表达，模型需要通过大量全连接权重自己学习这种关系。

4.2 CNN 使用参数共享

一个卷积核可以在整张图像的不同位置寻找同一种模式，例如水平边缘或垂直边缘。这个机制就是参数共享：同一组权重被重复应用到不同空间位置。

MLP 通常为不同输入位置使用不同连接权重，参数量更大，也不能天然复用“同一种模式出现在别的位置”这一事实。

4.3 CNN 能逐层提取层级特征

CNN 的前面层可以学习边缘、颜色和简单纹理，中间层组合出局部形状，后面层进一步形成更复杂的物体部件和语义特征。

Day 2 的 LeNet 已经体现了“卷积/池化 -> 更高层特征 -> 分类器”的数据流；Day 3 的 ResNet 则在更深网络中用残差连接改善特征传递；Day 4 的预训练 ResNet18 直接复用了这些已经学好的层级视觉特征。

4.4 对比总结

对比点 纯 MLP CNN
输入处理 通常先展平 保留 [C, H, W] 空间布局
局部关系 需要靠权重自己学习 局部感受野显式建模
参数使用 不同位置通常使用不同权重 卷积核跨位置共享
特征学习 缺少图像先验结构 从局部到整体逐层提取

五、阶段三最终结论

本周通过卷积基础、LeNet、残差网络和 ResNet18 迁移学习，完成了从 CNN 基本操作到预训练模型应用的学习闭环。CNN 比纯 MLP 更适合图像，是因为它能够利用局部空间结构，通过参数共享复用视觉模式，并逐层提取从边缘到高层语义的层级特征。

本次 ResNet18 实验在 2 个 epoch 内取得了最佳 validation accuracy 87.14% 和最终 test accuracy 86.67%。训练与验证指标都在改善，没有明显过拟合现象；但训练轮数较少，因此这个结果主要证明迁移学习流程已经跑通，不能视为充分训练后的最终性能。

六、易错点

  1. requires_grad=False 只控制参数是否参与梯度计算，不等于 model.eval()。
  2. model.eval() 会切换 BatchNorm / Dropout 的行为，但不会自动关闭梯度；关闭梯度要使用 torch.no_grad()。
  3. 冻结 backbone 后，新的分类头必须保持可训练；替换 fc 与冻结参数的顺序不能弄反。
  4. validation 用于选择最佳模型，test 只用于最终评估，不能根据 test 结果反复调参。
  5. 验证准确率高于训练准确率不必然是错误，要结合数据增强、train() / eval() 和 BatchNorm 行为解释。
  6. 2 个 epoch 的结果可以用于流程复盘，但不能直接当作模型最终上限。
